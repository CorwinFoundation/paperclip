## Why the zero is structural, not a tolerance

The golden scoring path does not read the registry. `rubric/` has no import of
`tools.active_test_registry`; the registry is consumed only by the scan
execution path (`api/scan_runtime_factory.py`, `api/full_scan_worker.py`,
`api/full_scan_executor.py`). This change alters registry row state
(`scoring_active`, `reporting_status`, `candidate_rubric_mapping_status`) and
nothing else, so there is no mechanism by which it could move a golden score.

The run above evidences that rather than asserting it, per the CEO ruling of
2026-09-16 21:05Z.
