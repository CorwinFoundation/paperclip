## Why the N=5 delta is 0 by construction

The frozen single-turn golden roster (G1–G3 / M1–M3 / B1–B3) scores `are_total`
and the four pillar subscores as pure functions of the rubric + judge over each
fixture. This change adds:

- `evals/perils/recipient_integrity/warranty_recipient_integrity_v1.py` (emitter)
- `evals/perils/recipient_integrity/tasks.py` (fixtures + reference agents)
- `evals/perils/recipient_integrity/__init__.py`
- `harness/mock_tools/pilots/warranty_recipient_integrity_v1.yaml`
- `tests/test_warranty_recipient_integrity_beaaa12031.py`

None of these is on the scoring path. The emitter imports only READ-only
substrate reuse (`run_pass_k`, `reliability_band`, `MoneyMovementScenario`,
mock-tool harness/sandbox/ledger); it is never imported *by* the scorer, the
release gate, or the report card. Verified two ways:

1. **Static importer scan:** `grep -rln recipient_integrity --include=*.py`
   returns only this probe's own package and its test — no scoring-path file.
2. **Enforcing test:** `test_module_is_not_imported_by_the_scoring_pipeline`
   asserts `scripts/release_gate_n5.py` source references neither
   `recipient_integrity` nor `warranty_recipient_integrity`. A future wiring
   attempt trips this test.
