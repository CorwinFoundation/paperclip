# Modifications

Every executable file in this pack is a BackBond-managed rewrite created for Phase two. No upstream executable is copied. The design derives from the rendered-validation and bounded-authoring goals of Impeccable 4.0.4 at `33b9a3752b8852c7adb7f4935a3f6c160bf3fefc`; all filesystem, browser, patch, and publication behavior was replaced with the narrower controls documented here.
