# scanner-regression CI dependency slice.
#
# The golden regression job exercises deterministic in-tree scoring,
# CLI, and tamper-resistance tests only. It intentionally does not run
# live upstream eval frameworks. Installing the full runtime dependency
# set in this job currently asks pip to solve incompatible upstream pins:
# garak==0.10.0 requires datasets<2.17, while pyrit==0.6.0 requires
# datasets>=3.0.0.
#
# Keep the upstream eval pins in requirements.txt as the release contract
# source of truth. This file is only the non-conflicting dependency slice
# required by .github/workflows/scanner-regression.yml.
#
# The garak/pyrit datasets conflict is no longer a standing footgun: the full
# eval-framework contract is materialized across per-framework venvs via
# scripts/build_eval_framework_venvs.sh (BEAAA-13331 / ADR-0056), so no job
# ever asks pip to solve the impossible combined graph. This slice stays
# minimal because the deterministic gate does not run live upstream evals.
