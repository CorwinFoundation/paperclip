# Continuous agent exposure evidence

Eight `synthetic-target-exposure@1` cases extend the existing actual-target
session path: in-workflow revocation, preview/action binding, memory poisoning
and correction, delegated result containment, tool-definition changes,
auxiliary disclosure, workflow budgets/STOP, and privacy differencing.

Each uses generated facts and scanner-owned inert tools, exact response/call
checks, permitted-task controls, at most twelve actual sends, and no model
judge. Captures retain original exchanges, ordered attempted effects and
delivered results. Assessor import replays these bytes rather than trusting
the recorded verdict or measurements. Unsupported sessions and missing output
surfaces remain unobserved; observed failures survive later acquisition errors.

Normal full-registry scans select these conditional cases through the existing
tool-session capability gate. Fixed packs keep their explicit membership.
Existing global request budgets and transport protections remain authoritative.
Generated scenario volume is not a count of live observations.

Auxiliary disclosure inspects supported message fields already returned by the
endpoint, including exposed reasoning fields, annotations, citations and error
envelopes. It never requests private internal reasoning. Provider transport
exceptions are not copied into captures; missing surfaces are unobserved. It
does not establish protection of logs or streams that the configured adapter
cannot observe.

Memory and catalogs are synthetic. Revocation/approval tests observe attempted
actions after visible trusted changes. A sandbox denial cannot establish native
production enforcement. Native IAM, stores, A2A/MCP authentication, concurrent
executors, quotas and downstream effects require access to those components.

## History

`agent-exposure-history/v1` tracks cases that have shown an exposure. Passing
coverage remains in the evidence inventory. States are newly observed,
persistent, cleared on a comparable retest, reopened, unobserved and not
comparable. Scope binds tenant and agent; comparison fingerprints bind supplied
target/configuration settings and case versions. Hidden deployment/model changes
are not established by these fingerprints.

Skipped, incomplete, conflicting, missing-version and changed-condition results
never clear a prior exposure. First/last exposure times persist, with the latest
twenty events per case. A successful comparable retest means the exposure was
not reproduced under those conditions. It is not a universal assurance claim.

The API stores history in the existing tenant-scoped scan log, carries the
previous projection through asynchronous manifest refreshes, and includes the
current history and recent per-scan events in standard responses and HTML reports.
Known cases reuse the shared scanner/listener/static exposure IDs; unmapped cases
keep their stable case identity without an inferred taxonomy classification.
Family associations remain candidates until a mechanism-specific diagnostic
supports classification; a format or utility failure is not labelled a secret leak.
No scheduler or listener
integration is added: recurring probes are repeated tests, while intervening
production activity requires native telemetry.

Assessor packs include `exposure-history.json` and `exposure-history.csv`, derived
only from accepted original captures in the pack. To include earlier scans,
explicitly bind those originals through the existing approved-plan importer.
Omitted observations never clear a previous failure. The pack contains original
bytes and checksums for replay; collection authenticity still requires review.

## Mappings

EU/ISO mappings advance to @10, NIST and OWASP 2025 to @4. OWASP 2025 IDs remain
unchanged. Separately versioned OWASP LLM 2026 and Agentic 2026 crosswalks are
added at @1. Empty candidate lists remain empty for native risks these synthetic
probes cannot observe. AIUC-1's existing October 15, 2026 crosswalk is extended
to the new observed tests at 1.1.2. All are candidate technical observations;
applicability, complete outcome coverage and certification are not inferred.
