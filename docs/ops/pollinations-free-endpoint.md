# Anonymous Pollinations scans

On 24 October 2026, the original anonymous `https://text.pollinations.ai/openai` endpoint returned HTTP 402 with error code `FREE_LIMIT` and a stated limit of one reply every 30 seconds per IP. A fresh request after waiting returned HTTP 200, the expected answer, `finish_reason: stop` and `user_tier: anonymous`. The earlier 100-case attempt had only 27 usable replies, with 45 payment-required responses and 28 timeouts. Its saved results cannot become complete evidence through report edits.

The adapter waits at least 31 seconds after each attempt finishes for this exact HTTPS endpoint, the supported JSON chat transports and explicit authentication `none`. A live preflight received `FREE_LIMIT` when starts were 31 seconds apart but the earlier response took several seconds; completion-based pacing preserves the full cooldown. It retries the same request at most three times, only for the endpoint's explicit HTTP 402 `FREE_LIMIT` response. A valid numeric Retry-After up to 60 seconds is respected without shortening the delay. Longer or malformed delays, billing errors and authentication failures remain failures. Requests retain their selected model, body, credentials, endpoint and existing egress guards.

The adapter allows up to 90 seconds for a response, bounded by the scan deadline. It accepts only replies with the provider's `finish_reason: stop`, preserves the full reply up to the existing Findings case limit of 65,536 characters, and refuses larger replies. The raw HTTP cap remains 256 KiB. No truncated text is presented as complete evidence. Findings ingestion retains its 2 MB whole-request bound and independent review gate.

For `starter-100@4` on this endpoint, the walker and parent budgets include 3,100 seconds of pacing allowance in addition to their existing 1,500 and 1,800 second budgets. The Scorer's inter-row timeout adds 421 seconds to its normal row/grading allowance: initial pacing, three 90-second attempts and two maximum 60-second Retry-After waits. Other endpoints and packs retain their existing deadlines. Probe, token, cost, credential and CI-routing policies are unchanged. This allowance supports a longer scan on the existing service; it does not buy provider capacity or bypass its quota.

A replacement run must have its own accepted request, selected form, timestamps and report workflow. Preserve the incomplete original and its review history. Only genuine independent SHIP can release the replacement's authenticated website link to info@backbond.ai.
